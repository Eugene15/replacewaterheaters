# GEO workflow

## Baseline

Collect a baseline before the first expected brand mention. Reuse a stable prompt set on a schedule so change is measurable.

## Observation fields

Store prompt, platform, visible model, date, language, geographic context, raw answer, mentioned brands, recommended brands, order/position, sentiment, citations, brand claims and availability state.

## Metrics

- mention share;
- recommendation share;
- citation share;
- sentiment;
- canonical-fact accuracy;
- competitor displacement;
- citation-source gaps.

Do not treat an AI citation as an organic rank. Do not use normal search results as fabricated AI observations.

## Actions

Create owner-approved proposals for content clarification, factual correction, original evidence, legitimate editorial authority, real review/reputation work and repeated buyer questions. Never create fake reviews, identities, locations, community posts or citations.
